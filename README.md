# 🌸 FLORA — Персональний трекер задач та регулярності

**FLORA** — це інтерактивний вебзастосунок у темній темі для управління задачами та відстеження продуктивності, створений на чистому HTML, CSS та JavaScript. Проєкт поєднує Kanban-дошку, аналітику прогресу, трекер регулярності та гейміфікованого **віртуального компаньйона-рослину (Rosie)**, яка росте разом із виконаними задачами.

## ✨ Основні можливості

- **Інтерактивна Kanban-дошка**: організація задач за трьома етапами — *In Plan / To Do*, *In Progress* та *Done* — із підтримкою перетягування (Drag & Drop) та автоматичним підрахунком карток у кожній колонці.
- **Повний цикл роботи із задачами (CRUD)**: створення, редагування, дублювання та видалення карток через зручне модальне вікно та контекстне меню.
- **Розумна фільтрація та пошук**: миттєвий пошук за назвою або описом, фільтрація за тегами (`All tasks`, `Today`, `Dev`, `Study`) та рівнем пріоритету (`All Priorities`, `High`, `Medium`, `Low`).
- **Гейміфікована рослина-компаньйон («Meet Rosie»)**: кожні 3 виконані задачі підвищують рівень рослини від насінини (`🌱`) до квітучої квітки (`🌸`), мотивуючи досягати тижневої цілі.
- **Вкладка аналітики та регулярності**: окремий екран статистики із відсотком виконання, розподілом задач за статусами, категоріями та пріоритетами.
- **Персоналізація та збереження даних**: зміна назви робочого простору й імені рослини, гарячі клавіші (`N` — нова задача, `/` — пошук, `Esc` — закрити модальне вікно) та збереження всіх даних у `localStorage`.

## 🛠 Технології

- **HTML5** — семантична розмітка дашборду, модальних вікон та сторінки входу.
- **CSS3** — сучасний дизайн у темній темі, сітки CSS Grid та Flexbox, адаптивність і плавні анімації.
- **Vanilla JavaScript (ES6+)** — управління станом застосунку, робота з DOM, HTML5 Drag & Drop API, система фільтрів та робота з `localStorage`.
