## 🎯 План реалізації за рівнями

### 🟢 Рівень BASIC — "It Tracks Tasks"
*Базовий функціонал роботи з завданнями та збереження даних на диск.*

1. **Модель даних (`src/taskModel.js`)**:
   - [ ] Створити структуру об'єкта `Task`:
     - `id` (унікальний ідентифікатор через `crypto.randomUUID()`)
     - `title` (назва завдання)
     - `status` (`TODO` | `IN_PROGRESS` | `DONE`)
     - `createdAt` (timestamp створення)
   - [ ] Додати валідацію: перевірка на порожню назву `title` та обмеження за довжиною.

2. **Сховище даних (`src/storage.js`)**:
   - [ ] Реалізувати читання з файлу `data/tasks.json` та запис у нього.
   - [ ] Обробити випадок, коли файл/папка відсутні (автоматичне створення).
   - [ ] Реалізувати **атомарний запис (Atomic Write)**: запис у тимчасовий файл `tasks.json.tmp` із подальшим перейменуванням (`fs.promises.rename`), щоб уникнути пошкодження даних при раптовому вимкненні.

3. **Базові CRUD-операції**:
   - [ ] Додавання нового завдання.
   - [ ] Отримання списку всіх завдань.
   - [ ] Зміна статусу (`TODO` $\rightarrow$ `IN_PROGRESS` $\rightarrow$ `DONE`).
   - [ ] Видалення завдання за `id`.

### 🟡 Рівень STANDARD — "It's a Real Tool"
*Повний CRUD, редагування, розширені поля, дедлайни та фільтрація.*

1. **Розширення моделі `Task`**:
   - [ ] Додати нові поля:
     - `priority` (`LOW` | `MEDIUM` | `HIGH`)
     - `deadline` (дата у форматі YYYY-MM-DD)
     - `tags` (масив рядків, наприклад `["backend", "bug"]`)
     - `updatedAt` (timestamp останнього редагування)

2. **REST API / Сервер (`src/server.js`)**:
   - [ ] Налаштувати Express-сервер з ендпоінтами:
     - `GET /api/tasks` — отримання завдань
     - `POST /api/tasks` — створення завдання
     - `PUT /api/tasks/:id` — оновлення/редагування завдання та його статусу
     - `DELETE /api/tasks/:id` — видалення завдання
   - [ ] Додати підтримку **фільтрації та пошуку** (через query-параметри):
     - За статусом (`?status=TODO`)
     - За пріоритетом (`?priority=HIGH`)
     - За тегом (`?tag=backend`)
     - Текстовий пошук за підрядком у назві (`?search=fix`)
   - [ ] Реалізувати спеціальне представлення **"Сьогодні" (`GET /api/tasks/today`)**:
     - Відображає завдання, дедлайн яких сьогодні, а також протерміновані завдання (Overdue).

*Інтерактивний веб-інтерфейс для візуалізації та зручного керування.*

1. **Фронтенд-інтерфейс (`public/index.html` & `public/style.css`)**:
   - [ ] Розробити UI з трьома колонками: **To Do**, **In Progress**, **Done**.

   - [ ] Реалізувати можливість перетягування карок між колонками (або кнопками швидкого переміщення).
